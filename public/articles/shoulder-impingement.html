「肩を上げると痛い」「夜うずいて眠れない」。整形外科で最も多い訴えのひとつが肩のインピンジメントです。かつては安静と注射が中心でしたが、2025年に相次いだ大規模研究は、まったく別の道筋を指し示しています。本稿では最新エビデンスをもとに、現場で使えるリハビリ戦略を整理します。

Update / 病名の捉え方

01「インピンジメント」から「RCRSP」へ

近年の文献では、従来の肩峰下インピンジメント症候群（SAIS）という呼び方そのものが見直されています。骨が腱を「挟み込む（インピンジ）」という構造的なイメージが、原因を過度に単純化してしまうためです。

代わって広く使われるようになったのが RCRSP（Rotator Cuff-Related Shoulder Pain／腱板関連肩痛） という包括的な用語です。これは腱板腱症・肩峰下インピンジメント・肩峰下疼痛症候群などを束ねた傘の概念で、痛みの原因が単一の構造ではなく、加齢・負荷の履歴・力学・心理社会的因子など多因子であることを前提にしています。

Key Point

名前が変わったのは流行ではなく治療方針の転換を意味します。「どこが挟まっているか」を画像で探すより、「どう動かすと痛むか・どこまで負荷をかけられるか」に焦点が移っています。

Evidence / 画像診断の落とし穴

02MRIの異常 ≠ 痛みの原因

2025年の臨床ガイドライン（Desmeules ら, JOSPT）が繰り返し警告しているのが、過剰な医療化（overmedicalization）と画像への過度な依存です。腱板の部分断裂や石灰化は、痛みのない肩にも高頻度で見つかります。つまり画像所見と症状は必ずしも一致しません。

Evidence

2025年のガイドラインは、診断は問診と身体所見を軸に行い、ルーチンの画像撮影には慎重であるべきと位置づけています。早期のMRIは不要な不安や手術志向を生みやすいことが指摘されています。

臨床的には、「動かしたときの痛みの再現性」を複数のテストで確認するクラスター評価が推奨されます。1つの整形外科テスト単独では精度が不十分なためです。

Core Strategy / 治療の主役

03第一選択は「漸進的な運動療法」

最新のエビデンスが最も強く支持するのは、手術でも注射でもなく運動療法です。2025年の Physical Therapy 誌のメタ解析（Lazzarini ら）は、ステロイド注射と理学療法介入を比較し、注射の鎮痛効果は短期的・一過性にとどまる一方、運動療法は単独でも有力な治療選択肢になりうると結論づけています。注射特有の有害事象リスクも考慮すべき点として挙げられました。

Caution

ステロイド注射が「効かない」わけではありません。短期の痛みは和らぐことがありますが、中〜長期では運動療法との差が消える傾向があり、腱組織への影響も完全には否定されていません。注射は運動を始めるための「橋渡し」と捉えるのが現代的な使い方です。

FITTの原則 ― 何が効果を決めるのか

2024年の JOSPT 系統的レビュー（FITT原則に基づく解析）は、特定のエクササイズ「種目」よりも、個別化・監督下・漸進的（progressive）であることそのものが効果を左右する可能性を示しました。種目選びに悩むより、負荷を着実に上げていく設計が重要だということです。

  • Frequency（頻度）：週3回程度を目安に継続。短期集中より習慣化。
  • Intensity（強度）：痛みを0〜3/10程度に抑えつつ、漸進的に負荷を上げる。
  • Time（時間）：1回あたり数十分、最低でも6〜12週の継続で評価する。
  • Type（種類）：腱板＋肩甲骨周囲筋を中心に、目的に応じて選択。
Hands-on / 肩甲骨アプローチ

04肩甲骨コントロールという土台

腱板だけを鍛えても肩は安定しません。土台となる肩甲骨（肩甲胸郭関節）の動きと安定性が崩れると、肩甲上腕リズムが乱れ、肩峰下スペースで腱がストレスを受けやすくなります。

2026年に発表されたRCT（Springer / BMC Musculoskeletal Disorders）では、標準的理学療法に肩甲骨安定化・モビライゼーションを追加した群が、12週時点で痛み（VAS：安静時・運動時・夜間とも）と機能（Constant、QuickDASH）で有意に優れた結果を示しました。肩甲骨へのアプローチが上乗せ効果を持つことを裏づけています。

とくにオーバーヘッド動作の多い競技者では、肩甲骨ディスキネジア（異常運動）に的を絞った運動が、汎用的な複合理学療法よりも持続的で包括的な効果を示したとする2025年のRCTも報告されています。「その人の崩れ方」に合わせる個別化が鍵です。

Protocol / 段階的プログラム

053フェーズで組む実践プログラム

現場では、痛みのコントロールから機能的負荷まで段階的に進める設計が扱いやすいです。下記は最新エビデンスを踏まえたモデル例です（あくまで一般的な枠組みで、実際は個別評価に基づき調整します）。

PHASE 1

鎮痛・可動性

  • 痛みの出ない範囲での自動運動
  • 後方関節包・小胸筋のストレッチ
  • 振り子運動・肩甲骨セッティング
  • 夜間痛の管理
PHASE 2

筋活性・コントロール

  • 外旋筋の遠心性トレーニング
  • 前鋸筋・下部僧帽筋の賦活
  • 肩甲骨面での挙上（scaption）
  • 閉鎖運動連鎖（CKC）課題
PHASE 3

漸進的負荷・復帰

  • 抵抗を漸増した複合運動
  • 競技・動作特異的トレーニング
  • 神経筋コントロール・反応課題
  • 再発予防の自主練習化
Tips

フェーズの移行基準は「日数」ではなく「課題の達成度」で判断します。痛みの再現性・可動域・基本的な肩甲骨コントロールが整ってから次へ進めると、後戻りが減ります。

Evidence Note

2025年の系統的レビュー（Wu ら, Frontiers in Bioengineering）は、個別化・監督下・漸進的で多種目を組み合わせた運動処方が RCRSP の痛みと機能改善に有効であることを示しています。上記3種は急性期〜回復期をカバーする組み合わせですが、症状が改善しない場合は必ず医療専門家の評価を受けてください。

Compare / 治療選択の整理

06主要な治療選択肢の比較

選択肢短期効果中〜長期位置づけ（2025〜）
漸進的運動療法緩やか良好で持続的第一選択。個別化・監督・漸進が鍵
肩甲骨アプローチ上乗せ効果機能改善に有利運動療法に併用で推奨
ステロイド注射あり（一過性）運動療法と差が縮小運動への橋渡しとして限定的に
PRP注射短期はステロイド同等機能面で優位の報告もエビデンス蓄積途上・費用課題
手術（除圧等）—保存療法と差が乏しい例も保存療法が無効な場合に検討

全体の傾向として、「まず保存療法（非手術）から始める」のが国際的な共通認識です。手術はあくまで十分な保存療法が奏功しなかった場合の選択肢と位置づけられています。

Takeaway / まとめ

072026年の肩リハビリ、5つの要点

  • 呼び名はRCRSPへ。 単一構造ではなく多因子で捉える。
  • 画像に頼りすぎない。 所見と痛みは一致しないことが多い。
  • 主役は漸進的運動療法。 注射・手術より前に十分に行う。
  • 肩甲骨を土台として鍛える。 腱板単独より上乗せ効果。
  • 個別化・監督・漸進。 種目より「設計」が効果を決める。
Conclusion

肩のインピンジメントは「動かさず守る」時代から「正しく動かして育てる」時代へ。痛みを恐れて固めるのではなく、評価に基づいて段階的に負荷をかけることが、最短で機能を取り戻す道です。
